Проверка Windy.app для WIND64

Подключитесь к той же Wi-Fi-сети, что и табло. API может плохо работать без VPN на роутере. VPN только на компьютере или телефоне не меняет маршрут ESP32.

Кнопки открывают API в новых вкладках. Эта страница не отправляет фоновых запросов и не читает ответы через CORS. Сначала проверьте станции, затем отдельно дождитесь полной загрузки прогноза.

Как выглядит успех

Браузер показывает полностью загруженный JSON с status: success. Для станций нужен непустой массив response.data, для прогноза — response.forecast и response.timezone: Europe/Moscow.

Открывающийся сайт или начало ответа ещё не доказывают успех: прогноз может зависнуть в процессе загрузки. Ошибка сети, обрыв, 403 или 429 требуют отдельной проверки. Не обновляйте API много раз подряд.

Проверить само табло

Откройте http://wind64.local/api/status или IP табло с окончанием /api/status. После первого подключения подождите 30–60 секунд. Ищите forecastReady: true, готовность обеих станций и lastHttp: 200 с ненулевыми successes в polling. Одного connected: true недостаточно.

Не публикуйте поля token и ssid из статуса устройства. Один успешный запрос не гарантирует постоянную доступность внешнего сервиса.
