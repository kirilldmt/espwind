# Проверки и ограничения

## Что проверяется автоматически

- **39 тестов** браузерного прототипа: время, календарь, семь дней начиная
  с сегодня, сессии, значения 0/null, свежесть, графики, цвета, частицы и кэш.
- **23 сценария / 115 RGB-кадров** C++ и JavaScript: побайтное совпадение,
  включая переходы сезонов, Новый год, високосный год, ошибки и направления ветра.
- Native-проверки планировщика: положительное случайное смещение, увеличение
  пауз, Retry-After, общая пауза хоста, сохранение сроков при переподключении.
  Симуляция суток без случайного смещения даёт 408 запросов.
- Пороги PULKOVO: свежие данные до 60 минут, задержка с 60, устаревание с 90.
  Проверены точные границы с точностью до миллисекунды.
- Сборка для указанной платы с ESP32 core 3.3.7.

GitHub Actions повторяет unit-тесты, C++/JS-сравнение и сборку прошивки.
Дополнительные браузерные тесты запускаются локально с установленным Chrome:
`node firmware/tests/web.mjs` и `npm --prefix wind64-prototype run test:browser`.

## Что проверено на физическом комплекте

Исходники версии 1.1.1 работают на Waveshare ESP32-S3-RGB-Matrix с одной
RGB-Matrix-P3-64×64. Проверены запись esptool с контролем хэша, подключение
телефона к точке настройки, сохранение Wi-Fi и яркости, загрузка прогноза и
обеих станций. В версии 1.1.0 отдельно проверены короткое переподключение
Wi-Fi без сброса API-таймеров и плановое пятиминутное обновление KITEPITER.

Публичный комплект собирается заново с удалением домашнего пути из встроенных
строк компилятора. Его SHA-256 указан в релизе; он может отличаться от ранней
локальной сборки того же кода. Не выдаём совпадение версии за совпадение бинарного хэша.

Телефонная зарядка 27 Вт подошла автору проекта. Это наблюдение для одного
комплекта и выбранной яркости, а не испытание любой зарядки или полной белой
заливки на максимальной яркости.

## Практические ограничения

- Пять экранов и координаты фиксированы. Ручной выбор экрана есть в прототипе,
  но не в веб-настройках ESP32.
- Часы всегда московские, Wi-Fi только 2,4 ГГц; до синхронизации NTP действует
  ночной предел яркости.
- Обновление прошивки только по USB, погодный кэш в RAM.
- 25 FPS — целевая частота анимации. В аппаратном наблюдении отдельные циклы
  на запуске/переподключении превышали 40 мс; развёртка около 250 Гц получена
  от драйвера и не измерена осциллографом.
- Длительное отключение Wi-Fi, полное восстановление первоначальной flash,
  все варианты матриц и блоков питания отдельно не проверялись.
- API Windy.app сторонний; возможны изменения формата, ограничения и
  нестабильный прямой доступ. В частности, в одной домашней сети большой
  прогноз периодически обрывался без VPN на роутере при успешных ответах станций.

Локальные логи, IP, MAC, SSID, токены, NVS и резервные копии устройства не
включены в публичный репозиторий. Для воспроизводимых проверок используются
синтетические данные из исходников тестов.
